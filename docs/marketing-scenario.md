# 제조 AX 통합 관제·분석 — 마케팅 시나리오

2026-10-17 작성. 시연용 프로토타입(https://claude.ai/artifact/3KRN9TtPkZk6K1uqFvhuwR, 공유 전에는 작성자만 열 수 있음)과 처음 설계 컨셉(익스큐티브 뷰, 공정·설비 관제, AX 품질·인과 분석, ROI 리포트)을 함께 써서 만든 마케팅 시나리오다. 화면 조작 순서는 `docs/demo-story.md`, 점검 결과는 `docs/reports/08-전체-점검.md`를 따른다.

모든 수치는 가상 회사 "한결모빌리티 (가상)"의 가상 데이터이고, 고정 현재 시각 2026-09-30 14:30 기준이다. 금액은 시연용 가상 단가로 계산했다. 마케팅 자료에도 "가상 데이터 · 시연용"을 함께 적는다(6장 표현 원칙).

## 3. 핵심 메시지 세 가지와 근거

### 메시지 1. "한 기준의 숫자" — 회의에서 숫자를 맞추지 않는다

- 근거: 9월 전사 OEE 77.3%, 비가동 손실 466.7 백만 원이 경영 현황 카드, OEE·손실 분석 요약, 월간 보고서 PDF에서 같은 값이다. 사업장 4곳의 비가동 손실(32.1 + 364.9 + 3.0 + 66.6)을 더하면 전사 값이 된다.
- 보여 줄 곳: 경영 현황 카드 아래 "4개 사업장 가중 평균", "4개 사업장 합산" 문구 → OEE·손실 분석 → 보고서 PDF.

### 메시지 2. "AI가 먼저, 근거와 함께" — 판단은 사람이 한다

- 근거 1(설비): 아산 1,200톤 메인 프레스 건전성 64, 잔여수명 7~14일(중앙값 9일). 진동 4.5 mm/s(정상 2.1~2.6), 베어링 온도 54.6 ℃(정상 45.9~49.4), 신뢰도 93%. 예상 영향은 정지 4~11시간, 1.0~2.8 백만 원.
- 근거 2(품질): 김해 범퍼 커버 불량률이 직전보다 +0.77%p 늘었다. 원인 1순위는 금형 온도(고정측) 편차(영향 크기 3.62, 신뢰도 92%). 권장 조건을 적용하면 불량률 1.8% → 1.0%, 월 17.7 백만 원.
- 근거 3(신뢰): 도장 건조로 2호 이상 탐지를 품질 담당이 "온도 센서 교정 문제"로 기각했고, 그 기록이 지워지지 않고 남는다.

### 메시지 3. "효과는 금액으로 끝까지" — 투자 회수를 설명할 수 있다

- 근거: AX 적용(2026-04) 후 누적 효과 1,222.3 백만 원(확정 1,174.4 + 추정 47.9). 투자비 1,150.0 백만 원, 회수 시점 2026-10(예상). 잠재 효과 227.2 백만 원(연간)은 합계에 넣지 않았다.
- 적용 전후(기준선 2025-10~2026-03 대 적용 후):

| OEE | 75.5% | 78.0% | +2.4%p |
| 공정 PPM | 10,523 | 8,816 | −16.2% |
| 평균 고장 간격 | 7.5시간 | 9.9시간 | +31.6% |

- 보여 줄 곳: AX 성과·ROI에서 "고장 정지 감소" 661.4 백만 원을 눌러 계산식, 기준선, 단가, 가정, 겹침 처리를 펼친다.

컨셉에는 없지만 구현에서 차별점이 된 것(마케팅에서 꼭 말할 것):

1. 효과를 확정·추정·잠재로 나누고, 같은 손실을 두 번 세지 않는 원장
2. AI 결과마다 근거·신뢰도·모델 버전과 사람의 채택·기각 이력
3. 질문하면 근거와 화면 링크로 답하고, 모르는 질문은 지어내지 않는 AI 도우미
4. 업종 템플릿(자동차 부품, 식품·음료, 금속 가공)으로 시작하는 초기 설정
5. 역할별 첫 화면과 사업장 권한, 휴대폰에서 보는 경영 현황·알림 상세

## 5. 시나리오

형식별로 네 가지를 둔다. 공통 구조는 "문제가 보인다 → 원인을 찾는다 → 사람이 판단·처리한다 → 효과가 금액으로 잡힌다 → 보고서로 끝난다"이다.

### 5.2 시나리오 B — 현장 리더 심화 데모(20분)

대상: 공장장, 품질·설비 팀장. 시나리오 A의 3~10번 장면을 실제 처리까지 이어서 보인다.

1. 정비 처리 끝까지(5분, 아산 공장장): 정비 오더 WO-260922-5055를 승인 → 착수 → 완료(작업 12시간, 부품비 640만 원) → 효과 확인(피한 정지 240분). 결과: 연결된 알림이 조치 완료로 닫히고, 아산 리스크가 2건에서 1건으로 줄고, AX 효과에 1.0 백만 원이 추정으로 더해진다. 메시지: "처리 결과가 효과와 리스크에 바로 반영됩니다."
2. 클레임 역추적(5분, 아산 공장장): 고객사 B 클레임 → 로트 3개 → 공통 요인(용접 로봇 7호, 자재 로트, B조) → 전극 팁 사용 타점 2,878~2,904(다른 로트 667~2,296) → 같은 조건 로트와 출하 범위. 메시지: "클레임 원인과 영향 범위를 몇 번의 클릭으로 찾습니다."
3. AI가 틀렸을 때(3분, 관리자): AI 결과·판정 이력에서 도장 건조로 2호 기각과 사유. 메시지: "AI를 믿으라고 하지 않습니다. 근거를 보고 사람이 판단하고, 그 기록이 남습니다."
4. 데이터가 끊겼을 때(3분, 대표이사 또는 공장장): 경영 현황 리스크의 수집 중단 → 알림 상세. 수집 장치, 미수신 시작 14:05, 영향 설비 4대. 메시지: "끊긴 데이터는 0이 아니라 미수신으로 보입니다. 잘못된 숫자로 판단하지 않게 합니다."
5. 휴대폰(2분): 같은 알림 상세와 경영 현황을 휴대폰 폭에서. 메시지: "현장 밖에서도 확인하고 조치를 기록합니다."
