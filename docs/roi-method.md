# AX 효과 산정 방법

AX 효과 금액은 `src/data/roi`에서만 계산한다. 경영 현황(EXE-010), AX 성과(EXE-020), 경영 보고서(EXE-030)와 PDF는 같은 원장을 읽는다. 모든 단가와 투자비는 가상이며 "시연용"으로 표시한다.

## 1. 원칙

1. **기준선과 비교한다.** 기준선은 AX 적용 전 6개월(2025-10-01 ~ 2026-03-31)이다. SET-020에서 바꿀 수 있고, 바꾸면 원장을 다시 계산한다.
2. **생산량으로 보정한다.** 손실은 절대량이 아니라 단위당 비율(계획 가동 시간당 고장 시간, 총생산당 불량, 양품당 에너지)로 비교하고, 현재 생산량을 곱해 금액으로 만든다. 생산이 줄어 손실이 준 것을 효과로 세지 않기 위해서다. 에너지 절감은 측정·검증(M&V)의 일반 방식처럼 기준선 기간의 "생산량 → 사용량" 관계로 예상 사용량을 만들고 실제와 비교한다.
3. **한 손실은 한 번만 센다.** 손실 범주마다 금액을 내는 방법을 하나만 정한다(4장 표). 다른 방법으로 계산한 값은 근거로만 보여 주고 합에 넣지 않는다.
4. **보수적으로 잡는다.** 가정이 들어가는 값은 낮은 쪽을 쓴다(예: 회피한 고장의 정지 시간은 같은 고장 모드 과거 정지 시간의 중앙값).
5. **AX가 아닌 원인을 뺀다.** 설비 교체·증설 같은 별도 투자로 생긴 변화는 효과 원장에서 제외 항목으로 기록한다(가상 데이터에는 1건을 넣어 제외 표시를 보여 준다).

## 2. 효과 분류

| 분류 | 정의 | 합계 포함 | 표시 |
| --- | --- | --- | --- |
| 확정 | 기준선 대비 실제로 측정된 변화에 확정 단가를 곱한 값 | 포함 | 채움 |
| 추정 | 개별 사건에 가정을 더해 계산한 값(예: 예지 정비로 피한 고장) 중, 확정 항목과 겹치지 않는 범주 | 포함(따로 표시) | 빗금 |
| 잠재 | AI가 제안했으나 아직 채택·실행되지 않은 개선의 예상 효과 | 미포함 | 테두리 |

경영 카드의 "AX 효과"는 확정 + 추정이며 카드에 그렇게 적는다.

## 3. 손실 → 금액 환산

| 손실 | 금액 환산 | 단가 |
| --- | --- | --- |
| 라인 정지(고장·교체) | 납기 제약 라인(도장 1라인, 화성 조립 2개 라인): 정지 시간 × 라인 손실 단가. 그 밖의 라인: 잔업으로 만회한다고 보고 정지 시간 × 투입 인원 × 잔업 단가 | `lineLoss.*`, `overtimeLaborKrwPerHour` |
| 성능 손실(소정지·속도 저하) | 손실 시간 × 잔업 인건비. 생산 목표를 잔업으로 맞췄다고 보는 보수적 환산 | `overtimeLaborKrwPerHour` |
| 공정 불량 | 폐기 × (재료비 + 가공비) + 재작업 × 재작업 단가 | `products.*` |
| 고객 클레임 | 반품 수량 × 판매가 + 건당 처리비 | `priceKrw`, `claimHandlingKrwPerCase` |
| 에너지 | 사용량 × 단가 | `electricityKrwPerKwh`, `compressedAirKrwPerNm3`, `lngKrwPerNm3` |
| 정비 | 작업 시간 × 정비 인건비 + 부품비 | `maintenanceLaborKrwPerHour` |

## 4. 효과 항목

| 항목 ID | 효과 | 분류 | 계산 | 겹침 처리 |
| --- | --- | --- | --- | --- |
| `fx.breakdown` | 고장 정지 감소 | 확정 | (기준선 고장 시간 비율 − 현재 비율) × 현재 계획 가동 시간 × 라인 손실 단가 − 늘어난 예방·예지 정비 비용 | 예지 정비 사례(`fx.pdm.cases`)는 이 항목의 근거로만 표시 |
| `fx.pdm.cases` | 예지 정비로 피한 고장(사례별) | 근거 | 사례마다 피한 정지 시간(같은 고장 모드 중앙값) × 단가 | 합에 넣지 않음 |
| `fx.pdm.recent` | 예지 정비로 피할 고장(측정 전) | 추정 | 효과 확인 후 30일이 안 된 예지 정비: 기록한 피한 정지 시간 × 정지 단가(D-18). 정비 비용은 빼지 않음 | 측정 기간이 없어 확정과 겹치지 않음. 30일이 지나면 확정 측정값으로 옮겨 감(D-47) |
| `fx.performance` | 소정지·속도 저하 감소 | 확정 | (기준선 성능 손실 비율 − 현재) × 현재 가동 시간 × 잔업 단가 × 인원 | |
| `fx.defect` | 공정 불량 감소 | 확정 | (기준선 불량률 − 현재) × 현재 총생산 × 제품별 불량 단가 | AI 권장 조건을 채택한 라인은 근거에 채택 이력 표시 |
| `fx.claim` | 고객 클레임 감소 | 추정 | (기준선 월평균 클레임 비용 − 현재) — 건수가 적어 통계적 확정이 어렵기 때문에 추정으로 둔다 | |
| `fx.energy` | 에너지 절감 | 확정 | (기준선 모델 예상 사용량 − 실제) × 단가. 에너지원별 | `fx.energy.idle`과 겹치는 비생산 시간 사용량은 여기서 뺀다 |
| `fx.energy.idle` | 비생산 시간 낭비 제거 | 추정 | 조치 후 줄어든 비생산 시간 기저 사용량 × 단가 | |
| `fx.potential.*` | 채택 전 AI 제안 | 잠재 | 엔진의 예상 효과(권장 조건, 정비 제안, 누설 수리) | 채택·실행되면 해당 확정·추정 항목으로 옮겨 가고 잠재에서 빠진다 |
| `fx.excluded.*` | 제외 항목 | 제외 | AX와 무관한 변화(예: 설비 교체) | 금액은 0, 사유만 표시 |

## 5. 투자와 회수

- 투자비: `company.json`의 `ax.investment` 항목 합
- 운영비: 월 운영비 × 적용 개월 수
- 순효과(월) = 확정 + 추정 − 운영비
- 회수 시점: 누적 순효과 ≥ 투자비가 되는 첫 달. 아직 회수하지 못했으면 최근 3개월 평균 순효과로 예상 회수 월을 계산하고 "예상"으로 표시한다.
- 투자 수익률(ROI) = (누적 순효과 − 투자비) ÷ 투자비. 기간을 함께 적는다.

## 5-1. 전사 원장

전사 원장은 사업장 원장의 합이다. 기준선 비율을 전사로 한 번에 계산하면 사업장 구성 차이 때문에 사업장 합과 어긋나므로, 항목마다 사업장별로 계산해 더한다. 근거 패널의 입력값은 사업장별 행과 합계 행으로 보여 준다.

## 6. 근거 표시(P9)

효과 항목을 누르면 다음 순서로 펼친다.

1. 결과 금액과 분류
2. 계산식(기호와 한국어)
3. 입력값: 기준선 값(기간·표본 수), 현재 값(기간), 생산량 보정 값, 단가(적용 시작일)
4. 가정과 보수적 처리
5. 겹침 처리(무엇을 뺐는지)
6. 원본 화면 링크(OPS-020, QUA-020, MNT-020, ENG-010)
