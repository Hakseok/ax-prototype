## 테스트 (전체 26개 통과)

- OEE = 가용성 × 성능 × 품질, 전사 OEE = 사업장 시간 가중, 손실 금액 = 사업장 합
- 비교 기간 정의, 진행 중 교대로 인한 한쪽 쏠림 없음(오늘 대 전일 같은 시각 6% 이내)
- 지표 24개가 모두 값을 냄(AX 효과·건전성 최저값은 따로 검사)
- SC-01·02·04·08 엔진 결과, 결정성(같은 입력 → 같은 결과), 위험 설비 순서
- 원장 합계 = 확정 + 추정, 전사 = 사업장 합(2% 이내)
- AI 도우미: 예시 질문 7개 모두 의도·링크 있는 답, 같은 질문 같은 답, 지원 밖 질문은 안내

## 확인하지 못한 것

- 화면에서의 표시(5~7단계에서 화면을 만들며 확인)
- 지표·엔진 계산 속도는 테스트 환경에서 원장 계산 약 1~2초. 브라우저에서의 체감 속도는 5단계에서 확인한다.
