## PDF 보고서

- pdfmake 0.3.11(MIT)로 만든다. 글꼴은 `@ibm/plex-sans-kr` 1.1.0(OFL-1.1)의 WOFF를 `npm run fonts:pdf`로 TrueType으로 풀어 `public/fonts/`에 둔다(라이선스 문서 동봉). 내보내기를 누를 때만 불러온다.
- 4쪽: 표지·핵심 요약 / 핵심 지표·월별 OEE·사업장 실적 / AX 효과와 근거 / 주요 리스크·작성 기준. 모든 쪽에 "가상 데이터 · 시연용 가상 단가".
- 견본: `docs/reports/samples/경영보고서_2026-09_전사.pdf`, `경영보고서_2026-09_아산공장.pdf`
- 생성 시간: WOFF 그대로는 Node에서 4.8초, 브라우저(개발 모드)에서 65초였다. TrueType으로 바꾼 뒤 Node 0.2초, 브라우저 약 2초(글꼴 5MB 읽기 포함).
- 저장: Artifact 안에서는 `downloads` 기능으로 보는 사람에게 저장 확인을 받는다(게시할 때 `capabilities: {downloads: true}` 선언 필요). 로컬 실행은 일반 다운로드. Artifact 안에서 기능이 없으면 "이 화면에서는 파일 저장을 쓸 수 없습니다"로 안내한다.

- PDF 견본 4쪽을 열어 한글·표·차트·머리말·꼬리말을 확인했다.
- 화면 캡처: 창 기본 폭에서 경영 현황·AX 성과·경영 보고서(어둡게)와 PDF 뷰어를 확인했다.

## 고친 문제

- 막대 차트 값 축이 75%에서 시작해 차이가 과장됨 → 막대는 0부터(D-37)
- 카드 비교 문구가 길어 줄이 넘침 → "전월 대비 −0.9%p 악화"로 줄이고 정확한 구간은 마우스 설명(D-35). 0으로 반올림되는 변화는 "변화 없음"
- 보고서 3쪽이 A4를 넘음 → 4쪽으로 나눔
- 휴대폰 폭에서 리스크 패널이 차트 뒤로 겹침 → 한 열 배치 수정
- 금액 카드 문구가 좁은 폭에서 여러 칸으로 쪼개짐 → 한 덩어리로
- 사업장 하나를 고르면 전사 투자비·운영비로 회수 시점을 계산함 → 전사 범위에서만 계산(D-44)
- PDF 라이브러리가 모델의 목록을 바꿔 내보낸 뒤 미리보기 요약이 깨질 수 있음 → 복사본 전달
- PDF 표에서 글자 열까지 오른쪽 정렬 → 숫자 열만
