## 새로 만든 공통 부품

- `PatternSkeleton`: 정의 파일이 없는 이번 버전 화면을 패턴의 영역 배치(12종)로 그리는 빈 템플릿
- `MoneyCard`, `EffectMark`, `money.ts`: 금액 단위(백만 원·천 원·원), 확정·추정·잠재를 채움·빗금·테두리 + 글자로 구분, "시연용" 표시, 근거 링크
- `AiResultCard`: 결과 종류·대상·결론·신뢰도(상태색 아님)·근거 3개·예상 영향·모델·채택/기각(기각 사유 필수)
- `AssistantDrawer`: AI 도우미 드로어 틀(대화는 7단계)
- `/_catalog`: 토큰, 버튼 4종(명령·보조·판정·처리), 상태 배지, 지표 카드, 금액 카드, 효과 분류, AI 결과 카드, 입력, 라인 OEE 표, 차트

## 확인한 것

- `npm run check` 통과(토큰, 화면 정의, 라이선스, 테스트, 빌드)
- 1920×1080 DOM 점검: 메뉴 화면 32개 + 공통 3개를 전사·아산 두 선택으로 열어 제목, 화면 종류(빈 템플릿·다음 버전·범위 안내·권한 안내), 가로 넘침, 본문 스크롤, 콘솔 오류를 확인했다. 가로 넘침·콘솔 오류 없음.
  - 이번 버전 화면: 빈 템플릿. 다음 버전 화면: "다음 버전에서 제공" 안내. OPS-010을 전사로 열면 사업장 선택 안내.
  - 대표이사(조회 권한)로 AIX-030, SET-010, SET-030, SET-050, SET-070을 열면 "관리 권한이 필요합니다" 안내.
- 역할 전환: 5명 각각 첫 화면과 대메뉴 순서가 menu.json과 같다(경영진 EXE-010, 아산 공장장 OPS-010·아산, 김해 품질 QUA-020·김해, 설비 엔지니어 MNT-010·2개 사업장, 관리자 SET-010).
- `/_catalog`에서 밝게·어둡게 전환 시 모든 부품이 함께 바뀐다(캡처 확인).
- 게시용 빌드: 파일 250개, 22.4 MB(글꼴 굵기 축소로 v1의 486개에서 줄어 한 번에 게시 가능).

## 확인하지 못한 것
