# 3단계 보고 — 가상 데이터

## 만든 것

- `scripts/gen-data/`: lib(시드 난수 스트림, 시간, 달력), master, production, assets(센서·정비), quality(클레임·납품), energy, events(알림·AI 이력·수집 상태), index
- `npm run gen:data` → `public/mock/` 55개 파일, 17.0 MB

- `src/data/`: `loaders.ts`(파일별 로더), `production.ts`(교대·사건·로트 조회, 사업장별 캐시), `calendar.ts`(근무 달력), `energy.ts`(1시간 + 15분 결합, 기간 끝 비례 처리), `costs.ts`(단가 버전), `versions.ts`
- 테스트 `src/data/data.test.ts`(8개)

## 재현성

`npm run gen:data`를 두 번 돌려 `scripts/hash-mock.mjs` 해시가 같다(55 files, 동일). 시드는 company.json `seed`, 난수는 이름별 독립 스트림이라 한 부분을 고쳐도 다른 부분이 흔들리지 않는다.
