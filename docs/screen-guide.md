# 화면 가이드

2026-10-17 초안. v1 화면 구성 패턴 가이드(`D:\ems-prototype\docs\screen-pattern-guide.md`)를 이어받아 제조 AX 범위로 넓혔고, v1 전체 점검(`docs/reports/07-전체-점검.md`)의 변경 제안 G-1~G-9를 반영했다.

## 1. 목적과 적용 범위

| 항목 | 기준 |
| --- | --- |
| 대상 | 제조 공장의 생산·품질·설비·에너지·원가를 함께 보는 관제·분석 솔루션 |
| 기본 업종 | 자동차 부품(프레스·용접, 사출·도장, 정밀 가공, 모듈 조립). 업종 템플릿으로 지표 세트를 바꾼다 |
| 화면 기준 | 웹, PC, 1920×1080. EXE-010과 COM-020은 휴대폰 폭(48em 이하)까지 대응 |
| 사용자 | 역할 5종: 경영진, 공장장, 품질, 설비·정비, 관리자. 역할은 첫 화면과 메뉴 순서를 정하고, 권한 3단계(조회·편집·관리)는 버튼을 정한다 |
| AI | 가상 AI 엔진이 계산하고 화면은 결과·근거·신뢰도를 보여 준다. 사람이 채택·기각한다 |
| 금액 | 모든 금액은 가상 단가로 계산하고 "시연용"을 표시한다 |

사용 순서

1. `config/menu.json`에서 화면의 패턴을 확인한다.
2. 3장에서 패턴의 영역 구성과 필수 요소를 가져온다.
3. 6장의 공통 규칙으로 버튼, 상태, 숫자, 금액, AI 표시를 맞춘다.

## 2. 공통 화면 구조

v1과 같은 7개 영역에 AI 도우미 창을 더한다. 치수는 토큰으로 정의한다(`--shell-*`).

| 영역 | 치수 | 담는 것 |
| --- | --- | --- |
| 상단 바 | 높이 48 | 로고·회사명, 사업장 선택, 기준 시각, "가상 데이터"·"시연용", AI 도우미, 알림, 사용자(역할) |
| 메뉴 | 폭 220 | 대메뉴와 메뉴 2단계. 사용자 역할에 맞는 대메뉴를 위에 둔다. "다음 버전" 화면은 흐리게 표시한다 |
| 제목 줄 | 높이 48 | 경로, 화면 제목, 화면 ID, 기간 선택(조건 영역이 없는 패턴), 링크 복사, 주 버튼 |
| 조건 영역 | 내용에 따라 | 조회 조건과 조회 버튼. P1, P2, P7, P9, P10, P12, P13은 생략 |
| 툴바 | 높이 32 | 결과 건수, 보조 버튼, 내보내기 |
| 본문 | 약 1,670 × 800 | 패턴별 구성. 영역 사이 12, 바깥 여백 16 |
| 알림 센터 | 폭 360 | 오른쪽 드로어 |
| AI 도우미 | 폭 440 | 오른쪽 드로어. 알림 센터와 동시에 열지 않는다. AIX-010은 같은 내용을 본문 전체로 연다 |

- 사업장 선택은 모든 화면의 첫 조건이다. 전사 또는 개별 사업장이며 주소(`?site=`)에 담고 화면을 옮겨도 유지한다.
- 메뉴에만 있고 이번 버전에서 만들지 않는 화면은 "다음 버전에서 제공" 안내와 화면 설명 한 줄을 보인다.

## 3. 화면 패턴 13종

P1~P8은 v1과 같다. P9~P12는 이번 범위에서 새로 필요해 추가했다(decisions.md D-01). P13은 사용자가 그리는 공정도 때문에 추가했다(D-71).

| 패턴 | 쓰는 경우 | 영역 구성 | 필수 요소 |
| --- | --- | --- | --- |
| P1 현황 대시보드형 | 조건 없이 현재 상태를 요약해 본다 | 지표 카드 4~6개, 차트, 요약 목록 | 기준 시각, 비교 기간 대비, 이상 건 강조, 스크롤 없는 한 화면, 아래 단계 화면으로 가는 링크 |
| P2 배치도형 | 라인·설비 배치 그림 위에서 상태를 본다 | 배치 그림, 선택 설비 상세 패널 | 정상은 무채색, 미수신 표시, 상세로 이동 |
| P3 분석형 | 기간·대상·계층을 바꿔 가며 분석한다 | 조건, 대상·계층 선택, 차트, 데이터 표 | 구간 확대, 여러 계열 비교, 계층 내려가기(경로 표시), 폭포형 차트, 표 내보내기 |
| P4 조회형 | 조건으로 여러 건을 찾아 보고 내려받는다 | 조건, 툴바, 그리드 | 결과 건수, 정렬·열 고정, 합계 행, 내보내기 |
| P5 처리 목록형 | 처리할 건을 단계별로 모아 하나씩 처리한다 | 단계 탭, 목록, 내용·처리 패널, 처리 기록 | 단계별 건수, 담당자, 처리 버튼, 처리 기록, 효과 기록 |
| P6 등록·편집형 | 한 건을 입력하거나 설정을 단계별로 진행한다 | 구역별 입력(또는 단계 표시), 하단 고정 버튼 | 필수 표시, 입력 즉시 검증, 저장 전 이탈 경고, 단계형은 이전·다음 |
| P7 상세 랜딩형 | 링크로 들어와 한 건(알림, 설비)의 전말을 본다 | 요약, 추이, AI 결과, 기록을 한 열로 | 단독으로 이해되는 제목, 원래 화면 링크 |
| P8 마스터-디테일형 | 기준 데이터를 목록에서 골라 관리한다 | 목록·트리, 상세 패널 | 검색, 신규·저장·삭제, 변경 이력, 적용 시작일(단가·기준선) |
| P9 근거 추적형 | 요약 금액·지표가 어떻게 나왔는지 끝까지 펼쳐 본다 | 요약 카드, 항목 목록(분류별), 근거 패널(계산 단계) | 확정·추정·잠재 구분, 계산식과 입력값, 가정, 원본 화면 링크, 중복 제외 표시 |
| P10 보고서형 | 정해진 양식의 보고서를 미리 보고 PDF로 낸다 | 보고 기간 선택, 페이지 미리보기, 목차 | 화면과 같은 계산, 표지·작성 기준·"시연용" 표시, PDF 내보내기 |
| P11 원인 분석형 | 문제 집단과 정상 집단을 비교해 원인 후보를 찾는다 | 대상 선택(불량·로트·기간), 집단 비교 차트, 원인 후보 목록, 근거 패널, 권장 조건 | 비교 기준 명시, 후보별 영향 크기·신뢰도·표본 수, 채택·기각, 조치로 연결 |
| P12 대화형 | 질문으로 지표와 화면을 찾는다 | 대화 기록, 예시 질문, 답(값·근거·링크) | 지원 범위 안내, 답의 계산 근거, "가상 엔진" 표시, 같은 질문에 같은 답 |
| P13 공정도형 | 사용자가 그린 공정도(2.5D 입체 기본, 평면 전환) 위에서 설비 상태를 보거나(뷰어), 그 공정도를 그린다(디자이너) | 뷰어: 화면·보기(공정/에너지)·시점 툴바, 공정도, 선택 설비·알림 패널. 디자이너: 팔레트, 캔버스, 속성 패널 | 조회 전용(제어 없음), 정상은 무채색·미수신 표시, 게시본만 뷰어에 보임, 게시 전 검사, 대형 화면(어두운 전체 화면) |

패턴 선택 기준은 v1 4장을 따르고 다음을 더한다.

- **P1과 P9**: 지금 상태를 보면 P1, 숫자 하나의 출처와 계산을 설명해야 하면 P9.
- **P3과 P11**: 시간·계층으로 변화를 보면 P3, 문제 건과 정상 건을 비교해 원인을 좁히면 P11.
- **P5와 P7**: 여러 건을 처리하면 P5, 한 건을 링크로 받아 보면 P7. 설비 진단 상세(MNT-011)는 P7이다.
- **P2와 P13**: 기준정보로 자동으로 그린 라인 도식이면 P2(OPS-030), 사용자가 직접 그려 게시한 공정도면 P13(OPS-060).
- 한 화면에 두 패턴을 섞지 않는다. 다만 AI 결과 카드(6장)는 모든 패턴에 넣을 수 있다.

## 4. 역할과 첫 화면

| 역할 | 첫 화면 | 위에 두는 대메뉴 |
| --- | --- | --- |
| 경영진 | EXE-010 경영 현황 | 경영, 공장 운영, 품질 |
| 공장장 | OPS-010 공장 현황 | 공장 운영, 설비·정비, 품질, 에너지 |
| 품질 | QUA-020 품질 원인 분석 | 품질, 공장 운영 |
| 설비·정비 | MNT-010 설비 건전성 | 설비·정비, 에너지 |
| 관리자 | SET-010 초기 설정 | 설정·관리, AI |

역할은 화면을 가리지 않는다. 볼 수 있는 화면은 권한(`permission.view`)과 사업장 권한으로 정한다.

## 5. 메뉴

`config/menu.json`이 단일 출처다. 대메뉴 8개, 화면 ID는 대메뉴 약어 3자 + 3자리 번호(10 단위, 딸린 화면은 끝자리 1~9). 한 번 쓴 ID는 다시 쓰지 않는다.

| 약어 | 대메뉴 |
| --- | --- |
| EXE | 경영 |
| OPS | 공장 운영 |
| QUA | 품질 |
| MNT | 설비·정비 |
| ENG | 에너지·탄소 |
| AIX | AI |
| SET | 설정·관리 |
| COM | 공통 화면(메뉴에 올리지 않음) |

## 6. 공통 규칙

| 항목 | 규칙 |
| --- | --- |
| 영역 순서 | 제목 줄, 조건, 툴바, 본문, 합계 순서 |
| 제목 | 메뉴명, 화면 제목, 경로 마지막 단어를 같게 쓴다 |
| 주 버튼 | 강조 버튼은 화면당 1개. 조건 영역이 있으면 조회 버튼, 없으면 제목 줄 오른쪽 끝 |
| 버튼 순서 | 보조 → 주 버튼. 삭제·기각은 주 버튼과 떨어뜨려 왼쪽에 둔다 |
| 버튼 명칭 | `config/terms.json`만 쓴다(D-02) |
| 조회 조건 | 시간축이 있는 화면은 기간이 첫 번째. 기본 기간은 집계 단위에 맞춘다(7장). 시간축이 없는 기준정보 목록은 기간 조건이 없다. 펼친 조건은 5개까지, 나머지는 접는다 |
| 그리드 | 숫자는 오른쪽 정렬·고정폭 숫자, 단위는 머리글. 가로 스크롤이 생기는 주 그리드는 첫 열과 합계 행 고정. 단위가 섞이는 표는 "단위" 열을 둔다 |
| 상태 표시 | 긴급·주의·참고·정상 4단계. 색·도형·글자 병기, 정상은 무채색 |
| 시각 | YYYY-MM-DD HH:mm, 24시간제. 오늘 건은 시각만 |
| 숫자 형식 | 8장 표를 따른다 |
| 금액 | 9장을 따른다 |
| AI 결과 | 10장을 따른다 |
| 빈 상태·오류 | 이유와 다음 행동을 한 줄로 알린다. 예: "조회할 라인을 고른 뒤 조회를 누르세요." |
| 미수신 | 수집 중단 구간은 0으로 그리지 않는다. 시계열은 빈 칸, 일부 미수신인 집계 칸은 값 옆에 "미수신 n대" 표식, 누적값에는 "미수신 n대 제외"를 적는다 |
| 진행 중 구간 | 진행 중인 시간·교대·일은 다른 칸과 섞지 않는다. 차트에서는 점선 또는 "진행 중" 표시, 비교는 같은 경과 시점끼리 한다 |
| 링크 공유 | 조건을 주소에 담는다 |
| 권한 | 조회·편집·관리 3단계. 권한이 없는 버튼은 숨기고, 입력 화면은 "조회 권한으로 열었습니다"를 표시한다 |
| 팝업 | 확인·선택처럼 짧은 작업에만. 팝업 위에 팝업을 띄우지 않는다 |
| 사업장 범위 | 권한이 있는 사업장만 선택한다. 전사 비교 화면을 사업장 1곳 권한자가 주소로 열면 권한 안내를 보인다 |
| 전사 값 | 합산 값은 "n개 사업장 합산", 가중 평균은 "n개 사업장 가중 평균", 최댓값은 "n개 사업장 중 최고 · 사업장명"으로 표기한다 |
| 화면 ID | 제목 줄에 작게 표시한다 |
| 가상 표시 | 상단 바 "가상 데이터" 상시. 금액·단가·효과가 있는 화면은 제목 줄에 "시연용" 배지, PDF는 모든 쪽 머리말 |

## 7. 비교 기간과 기본 기간

비교 기간은 `src/data/period.ts`의 한 함수로만 계산한다(D-05).

| 오늘(현재 시각까지) | 전일 00:00 ~ 전일 같은 시각 | 전일 대비 |
| 이번 교대 | 직전 같은 교대의 같은 경과 시간 | 전 교대 대비 |
| 이번 주 | 전주 같은 요일·시각까지 | 전주 대비 |

| 올해 | 전년 같은 기간 | 전년 대비 |
| AX 효과 | 기준선 기간(월 평균) 대 적용 후 기간(월 평균) | 기준선 대비 |

| 집계 단위 | 기본 기간 |
| --- | --- |
| 15분·1시간 | 오늘 |
| 교대·일 | 최근 30일 |

## 9. 금액 표시

- 계산은 원 단위로 하고, 표시 단위는 화면 영역마다 하나로 고정한다.
  - 경영 화면 카드·차트: 백만 원, 소수 1자리(예: 1,234.5 백만 원). 10억 원 이상 카드는 억 원 소수 1자리를 쓸 수 있다.
  - 근거 패널·상세 표: 천 원, 정수
  - 단가: 원, 정수(원/개, 원/kWh, 원/시간)
- 머리글이나 카드 제목에 단위를 적는다.
- 효과 금액은 확정·추정·잠재 세 가지로 구분한다(roi-method.md). 색만으로 구분하지 않고 도형과 글자를 함께 쓴다.
  - 확정: 채운 막대·채운 점, 글자 "확정"
  - 추정: 빗금 막대·속 빈 점, 글자 "추정"
  - 잠재: 테두리만 있는 막대, 글자 "잠재"
- 합계에는 어떤 분류를 더했는지 적는다(예: "확정 + 추정"). 잠재는 합계에 넣지 않는다.
- 금액 옆에는 근거로 가는 링크(P9)를 둔다.

## 10. AI 결과 표시

AI 결과는 "AI 결과 카드" 부품 하나로 그린다.

| 요소 | 내용 |
| --- | --- |
| 머리 | 결과 종류(이상 탐지, 잔여수명, 원인 후보, 권장 조건), 대상, 생성 시각, "가상 엔진" 배지 |
| 결론 | 한 문장. 수치에는 단위와 구간을 붙인다(예: 잔여수명 7~15일, 중앙값 10일) |
| 신뢰도 | 높음(80% 이상)·보통(60~79%)·낮음(60% 미만) 글자 + 수치. 상태색을 쓰지 않는다 |
| 근거 | 상위 3개 신호·변수: 현재 값, 정상 범위, 차이. 근거 차트로 이동 |
| 영향 | 예상 영향(정지 시간, 불량 수량, 금액). 금액은 9장 규칙 |
| 판정 | 채택·기각(사유 필수). 판정자·시각을 기록하고 AIX-020 이력에 남긴다 |
| 모델 | 모델 이름, 버전, 학습 기간(가상) |

- AI 결과의 등급(긴급·주의·참고)은 알림 등급과 같은 4단계를 쓰되, 신뢰도와 섞지 않는다.
- 기각된 결과는 지우지 않고 "기각 · 사유"로 남긴다.
- 지원하지 않는 질문이나 근거가 부족한 경우 답을 만들지 않고 이유를 보인다.
