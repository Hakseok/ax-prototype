# 지표 사전

지표 계산은 `src/data/metrics`에서만 한다. 화면 정의와 업종 템플릿은 아래 지표 ID만 참조한다.

## 1. 기본 시간과 수량

OEE 계산의 기준이 되는 시간 구분이다. 설비·라인마다 교대 단위로 계산한다.

| 용어 | 정의 |
| --- | --- |
| 달력 시간 | 교대 길이(8시간 또는 9시간) |
| 계획 정지 | 휴식·식사(교대당 60분), 계획 휴무, 예방 정비 계획 시간 |
| 계획 가동 시간 | 달력 시간 − 계획 정지 |
| 정지 손실 | 고장, 금형·품번 교체 시간(가용성 손실) |
| 가동 시간 | 계획 가동 시간 − 정지 손실 |
| 이상 생산 속도 | 라인의 `idealRatePerHour`(company.json). 이상 사이클 = 3600 ÷ 이상 생산 속도(초) |
| 총생산 | 그 시간에 만든 수량(양품 + 불량 + 재작업 대상) |
| 양품 | 첫 검사에서 합격한 수량. 재작업 후 합격품은 양품에 넣지 않는다 |
| 완전 가동 시간 | 양품 × 이상 사이클 |

## 2. 지표 정의

합산 방식: **합** = 사업장 값을 더함, **시간 가중** = 분자·분모를 각각 더해 다시 나눔, **수량 가중** = 수량을 가중치로 평균, **최댓값** = 가장 나쁜 값과 사업장명.

### 생산·OEE

| ID | 이름 | 계산식 | 단위 | 합산 | 비고 |
| --- | --- | --- | --- | --- | --- |
| `plan.attainment` | 계획 달성률 | 양품 ÷ 계획 수량 | % | 분자·분모 합 | 진행 중 교대는 경과 시간만큼의 계획과 비교 |
| `oee` | 종합설비효율 | 완전 가동 시간 ÷ 계획 가동 시간 (= 가용성 × 성능 × 품질) | % | 시간 가중 | 라인 OEE는 라인 단위로, 설비 OEE는 설비 단위로 |
| `oee.availability` | 가용성 | 가동 시간 ÷ 계획 가동 시간 | % | 시간 가중 | |
| `oee.performance` | 성능 | (총생산 × 이상 사이클) ÷ 가동 시간 | % | 시간 가중 | 100% 초과는 이상 속도 설정 오류로 보고 100%로 자르고 데이터 품질 알림 |
| `oee.quality` | 품질 | 완전 가동 시간 ÷ (총생산 × 이상 사이클) | % | 시간 가중 | 라인 하나에서는 양품 ÷ 총생산과 같다. 여러 라인을 합칠 때도 OEE = 가용성 × 성능 × 품질이 성립하도록 시간 기준으로 둔다. 수량 기준은 `quality.fpy` |
| `loss.sixBig` | 6대 손실 | 분류별 손실 시간(아래 3장) | 시간 | 합 | 폭포형 차트: 계획 가동 시간 → 각 손실 → 완전 가동 시간 |
| `loss.downtimeCost` | 비가동 손실 금액 | Σ(정지 손실 시간 × 라인 손실 단가) | 백만 원 | 합 | 단가는 `lineLossKrwPerHour`. roi-method.md 3장의 환산 원칙 |

## 3. 6대 손실의 시간 환산

| 분류 | 그룹 | 손실 시간 |
| --- | --- | --- |
| 고장 | 가용성 | 고장 사건의 정지 시간 |
| 금형·품번 교체 | 가용성 | 교체 사건의 정지 시간 |
| 소정지 | 성능 | 5분 미만 정지의 합(사건으로 기록) |
| 속도 저하 | 성능 | 가동 시간 − 총생산 × 이상 사이클 − 소정지 |
| 공정 불량·재작업 | 품질 | (불량 − 초기 불량) × 이상 사이클 |
| 초기 불량 | 품질 | 교체 후 첫 30분 안의 불량 × 이상 사이클 |

검산: 계획 가동 시간 − 6대 손실 합 = 완전 가동 시간. 단위 테스트로 확인한다.

## 4. 생산일과 비교 기간

- 생산 실적은 교대 시작일을 생산일로 본다(3조 22:00~06:00은 시작한 날의 실적).
- 기간 끝이 끝난 교대의 중간에 걸리면 그 교대는 경과 비율만큼 잘라 계산한다. 진행 중인 교대와 같은 경과 시간끼리 비교하기 위해서다(D-20).

`docs/screen-guide.md` 7장을 따르고 `src/data/period.ts`의 한 함수로 계산한다. 진행 중인 교대·일은 같은 경과 시점끼리 비교한다. 데이터 범위 밖(예: 기준선 이전)이면 비교 값을 비워 두고 "비교 데이터 없음"을 표시한다.

## 5. 데이터 품질 규칙

- 미수신 구간이 있는 교대의 OEE는 수신된 시간만으로 계산하고 "미수신 n분 제외" 표식을 단다. 미수신 시간은 계획 가동 시간에서 빼서 "데이터 없음"으로 따로 집계하고, 정지 손실로 보지 않는다. 그래야 수집 중단이 고장이나 0 생산으로 보이지 않는다.
- 성능이 100%를 넘거나 양품이 총생산보다 많으면 계산값을 자르고 AIX가 아닌 "데이터 품질" 알림을 만든다.
