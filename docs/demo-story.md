# 경영진 시연 흐름 (초안)

8단계에서 실제 화면 기준으로 확정한다. 수치는 데이터 생성 후 채운다(지금 적힌 값은 자리 표시가 아니라 "어떤 종류의 수치를 말할지"를 뜻한다).

- 대상: 대표이사·임원, 공장장
- 시간: 10분 안팎 + 질의응답
- 사용자 전환은 COM-040(로그인)에서 사용자를 골라 한다. 각 사용자의 사업장 권한은 company.json `users`를 따른다(아산 공장장은 아산만, 김해 품질 담당은 김해만).
- 메시지: "흩어진 생산·품질·설비·에너지 데이터를 한 기준으로 묶고, AI가 근거와 함께 먼저 알려 주며, 효과는 금액으로 끝까지 설명된다."

## 예상 질문(8단계에서 답 확정)

- 이 금액의 근거는? → EXE-020 근거 패널
- AI가 틀리면? → 신뢰도 표시, 사람의 채택·기각, 기각 이력(SC-08)
- 우리 회사 데이터로는 얼마나 걸리나? → 연계 대상(MES, 설비, 에너지)과 초기 설정 흐름. 기간은 시연 범위 밖이라 별도 제안
- 데이터가 끊기면? → 미수신 표시(SC-07)
- 다른 업종도 되나? → SET-010 업종 템플릿
