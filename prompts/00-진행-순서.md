# AX 프로토타입 — 진행 순서와 공통 규칙

가상의 자동차 부품 회사(사업장 3~4곳, 프레스·사출·가공·조립)를 대상으로 "제조 AX 통합 관제·분석" 솔루션의 시연용 프로토타입을 만든다.
일반 제조 솔루션으로 설계하고, 업종별 지표는 초기 설정에서 제시·선택한다. 운영 시스템이 아니다.

먼저 만드는 것은 경영진 시연에서 효과가 큰 화면이다. 기준정보·시스템 관리 같은 일반 관리 화면은 메뉴에만 두고(“준비 중” 표시) 다음 버전에서 만든다.

## 모든 단계에 적용하는 규칙

- 한 단계가 끝나면 멈추고 보고한다. 다음 단계로 스스로 넘어가지 않는다.
- 설계 문서에 없는 것을 정해야 하면 멈추고 묻는다. 작은 결정은 `docs/decisions.md`에 기록하고 보고에 적는다.
- 각 단계 끝에 `npm run check`(토큰·화면 정의·라이선스 검사, 테스트, 빌드)가 통과해야 한다. 2단계 전에는 해당 없음.
- 화면을 만들면 1920×1080에서 직접 열어 겹침·잘림·콘솔 오류를 확인하고, 확인한 화면 ID를 보고에 적는다. 확인하지 못한 것은 확인하지 못했다고 적는다.
- 응답과 화면 문구는 한국어, 코드 식별자와 주석은 영어로 쓴다.
- 데이터
  - 모든 데이터와 금액은 가상이다. 금액·단가·효과가 나오는 화면에는 "시연용" 표시를 둔다. 상단 바에는 "가상 데이터" 표시를 항상 둔다.
  - 실제 회사명, 실제 제품·설비 번호, 출처를 확인하지 못한 통계는 쓰지 않는다. 외부 자료를 근거로 쓰려면 출처를 확인해 문서에 적는다.
  - 가상 데이터는 고정 시드로 생성한다. 화면에서 난수를 만들지 않는다. "현재"는 설정 파일의 고정 시각을 쓴다.
  - 같은 수치는 화면이 달라도 같은 값이어야 한다. 합계와 금액은 원본에서 계산하고 따로 적어 두지 않는다.
- AI
  - AI 결과는 화면에 보여 주되 계산은 가상 엔진(`src/data/aiEngine.ts`의 어댑터 + mock 구현)이 한다. 실제 모델이나 외부 API를 호출하지 않는다.
  - AI 결과에는 근거 데이터와 신뢰도(또는 구간)를 함께 보여 주고, 사람이 채택·기각할 수 있게 한다. 판정 결과는 이력으로 남는다.
- 라이선스: MIT, Apache-2.0, BSD, ISC, BlueOak-1.0.0, Zlib, 글꼴은 OFL만 쓴다. GPL·AGPL 계열과 AG Grid Enterprise 기능은 쓰지 않는다. 패키지를 추가할 때마다 라이선스를 확인한다.
- v1(`D:\ems-prototype`)은 수정하지 않는다. 쓸 만한 코드와 규칙은 복사해 와서 고친다.
