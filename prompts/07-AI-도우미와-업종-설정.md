# 7단계 — AI 도우미와 초기 설정(업종 템플릿)

## 할 일

1. AI 도우미
   - 상단 바에서 여는 대화 창. 질문을 가상 엔진이 해석해 답과 근거(지표 값, 기간, 사업장), 관련 화면 링크를 준다.
   - 예시 질문 목록을 제공한다(예: 이번 달 OEE가 가장 낮은 라인과 이유, 지난주 불량이 늘어난 원인, 다음 주 정비가 필요한 설비, 이번 달 AX 효과).
   - 해석하지 못한 질문은 지원하는 질문 범위를 안내한다. 답을 지어내지 않는다.
   - 답에 "가상 엔진" 표시와 계산 근거를 둔다. 같은 질문에는 항상 같은 답을 낸다.
2. 초기 설정(업종 템플릿)
   - 업종 선택 → 권장 지표 세트, 손실 분류, 품질 지표, 원가 항목, 단가 입력 순서로 진행하는 설정 화면
   - 업종을 바꾸면 경영 현황과 분석 화면의 지표 구성이 바뀌는 것을 시연할 수 있어야 한다. 데이터가 없는 업종(식품, 금속 가공)은 지표 구성과 화면 배치만 바뀌고 값은 "데이터 없음"으로 표시하는 등 처리 방법을 정해 보고한다.
   - 단가와 기준선 기간을 바꾸면 ROI가 다시 계산된다. 변경 이력과 적용 시작일을 남긴다.

## 완료 기준

- 예시 질문 전부가 정해진 답과 근거를 낸다. 지원하지 않는 질문에는 안내가 나온다.
- 업종 템플릿 전환과 단가 변경이 관련 화면에 일관되게 반영된다.
- `npm run check` 통과, 직접 연 화면 ID 보고
