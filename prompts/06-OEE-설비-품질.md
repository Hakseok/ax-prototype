# 6단계 — OEE·손실 분석, 설비 건전성·정비, 품질 원인 분석

경영 현황에서 한 단계 내려가 "왜 그런가"와 "무엇을 하면 되는가"를 보여 주는 화면을 만든다.

## 할 일

1. OEE·손실 분석
   - 사업장 → 라인 → 설비로 내려가며 OEE와 가용성·성능·품질을 본다.
   - 6대 손실을 폭포형 차트로 보여 주고 시간과 금액을 함께 표시한다.
   - 손실 상위 원인과 해당 비가동 사건 목록, 교대·제품별 비교
2. 설비 건전성·정비
   - 설비별 건전성 지수와 추이, 잔여수명(구간 포함), 근거 센서 신호
   - 이상 징후 → 정비 요청 → 승인 → 작업 → 결과 → 효과(예방한 정지 시간과 금액)까지 한 흐름으로 처리한다. 처리 이력이 남는다.
   - AI 결과는 근거·신뢰도와 함께 보이고 사람이 채택·기각한다.
3. 품질 원인 분석
   - 불량 유형·제품·라인·기간으로 좁히고, 불량 로트를 고르면 당시 공정 조건, 설비 상태, 금형, 자재 로트를 정상 로트와 비교한다.
   - 가상 엔진이 원인 후보를 순위·근거·신뢰도와 함께 보여 주고, 권장 조건과 예상 효과를 제시한다.
   - 고객 클레임에서 출발해 관련 로트와 출하 범위를 찾는 역추적
4. 화면 사이 이동: 경영 현황의 리스크 → 해당 분석 화면, 분석 화면 → 정비 요청·품질 조치. 조건은 주소에 담는다.

## 완료 기준

- OEE와 손실 금액이 경영 현황 값과 같다.
- 정비 흐름을 끝까지 처리하면 효과가 AX 성과 화면(추정 또는 확정)에 반영된다.
- 시나리오(설비 이상, 불량 급증, 성능 손실, 클레임 추적)가 각 화면에서 재현된다.
- 1920×1080에서 겹침·잘림·콘솔 오류 없음. `npm run check` 통과

끝나면 멈추고 보고해 줘.
