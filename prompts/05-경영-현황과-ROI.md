# 5단계 — 경영 현황, AX 성과·ROI, PDF 보고서

경영진 시연의 첫 장면이 되는 화면들을 만든다. 화면 ID와 패턴은 `config/menu.json`을 따른다.

## 할 일

1. 경영 현황(대표이사 첫 화면)
   - 한 화면(1920×1080, 스크롤 없음)에서 생산·품질·설비·원가·리스크를 본다.
   - 핵심 지표 카드: 계획 달성률, OEE, 품질(PPM 또는 FPY), 비가동 손실 금액, AX 효과 금액. 각 카드에 비교 기간 대비와 포함 사업장 수.
   - 사업장 비교, 주요 리스크(설비 이상 징후, 품질 이상, 납기 위험)와 예상 영향 금액, 바로 아래 단계 화면으로 가는 링크
2. AX 성과·ROI
   - 효과 금액을 확정·추정·잠재로 나눠 보여 주고, 항목을 누르면 기준선·현재·단가·가정까지 펼쳐 본다.
   - 적용 전후 비교(기준선 기간 대 적용 후 기간), 누적 효과와 투자비, 회수 시점
   - 모든 금액에 "시연용" 표시
3. PDF 보고서
   - 경영 현황과 AX 성과를 월간 보고서 형식(표지, 요약, 지표, 효과 근거, 주요 이슈)으로 만든다. 1단계에서 정한 방법으로 한글 글꼴을 넣는다.
   - 화면과 PDF의 수치가 같아야 한다(같은 계산 함수 사용).
   - Artifact로 게시했을 때 파일 저장이 막히는지 확인하고, 막히면 대안(게시 기능 사용 또는 로컬 실행 안내)을 보고한다.
4. 화면 정의는 `config/screens/`에 쓰고, 템플릿으로 안 되는 부분이 있으면 이유를 적는다.

## 완료 기준

- 전사 지표가 정의된 합산 방식대로 사업장 값과 맞는다.
- 경영 현황의 AX 효과 금액 = AX 성과 화면 합계 = PDF 합계
- 시나리오가 해당 화면에서 보인다(어느 시나리오가 어디에 보이는지 표로 보고).
- 1920×1080, 밝은·어두운 테마에서 겹침·잘림 없음. `npm run check` 통과

끝나면 멈추고, 화면 캡처와 PDF 견본을 첨부해 보고해 줘.
